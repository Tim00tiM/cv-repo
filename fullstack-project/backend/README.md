### Модель данных

- **Пользователь (User)**

  - id
  - имя / логин
  - email
  - пароль (хэш)

- **Узор (Pattern)**

  - id
  - владелец (user_id)
  - дата создания
  - параметры холста (размер, масштаб)
  - параметры диагоналей (цвета, тип диагонали) (вероятно придется придумать удобный способ хранения параметров)
  - изображение (сгенерированный результат / ссылка на него)
  - публичность (публичный/приватный)

- **Комментарий**

  - user_id
  - pattern_id
  - text

### Сценарии использования

- Пользователь создал новый аккаунт.
- Пользователь зашел в свой аккаунт.
- Пользователь получил все узоры.
- Пользователь получил все узоры конкретного пользователя.
- Пользователь оставил комментарий к узору.
- Пользователь создал новый узор.

# Проект "Генератор узоров"

## Общая концепция

Проект представляет собой веб-приложение, позволяющее пользователям создавать, сохранять и делиться узорами.  
Узор задаётся параметрами холста и набором диагоналей с выбранными цветами. На основе этих правил сайт генерирует повторяющийся паттерн, который автоматически продолжается на всём холсте.

Основная цель — дать пользователям удобный инструмент для творчества и обмена визуальными паттернами.

---

## Страницы сайта

1. **Главная страница** — описание сервиса, последние добавленные узоры, кнопка "Создать узор".
2. **Создание узора** — интерактивный редактор (выбор размера холста, добавление диагоналей, выбор цветов).
3. **Галерея узоров** — просмотр опубликованных узоров других пользователей.
4. **Страница узора** — просмотр конкретного узора, возможность лайкнуть/поделиться/сохранить.
5. **Личный кабинет** — список собственных узоров, настройка профиля.
6. **Регистрация/авторизация** — для сохранения и публикации узоров.

---

## Сущности базы данных

- **Пользователь (User)**

  - id
  - имя / логин
  - email
  - пароль (хэш)

- **Узор (Pattern)**

  - id
  - владелец (user_id)
  - дата создания
  - параметры холста (размер, масштаб)
  - параметры диагоналей (цвета, тип диагонали) (вероятно придется придумать удобный способ хранения параметров)
  - изображение (сгенерированный результат / ссылка на него)
  - публичность (публичный/приватный)

- **Комментарий**

  - user_id
  - pattern_id
  - text
